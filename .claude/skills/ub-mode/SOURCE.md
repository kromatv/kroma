## What the project overrides

A project's own documents beat a skill, and two lines of this one do not hold in
a repository that works through pull requests:

- "Push to the main line at the end": a change goes on a branch and through a
  pull request. Commit there, and push only when asked.
- The skill's tools (`crapper`, `dryer`, `mutator`) are run through the
  project's own commands where it has them, at the project's own thresholds.
