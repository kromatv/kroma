Any Tabler glyph (`tabler.io/icons`), by name. There is no registry to add to and no generated file: `wave-sine` draws because Tabler exports `IconWaveSine`, and the name is translated into the export. A name the package does not have draws `help-circle` instead of crashing, which is what makes it safe to take an icon name from **data** - a server-installed module names its glyph in its own manifest, and no list could ever be complete.

This story is the component: sizes, weight, colour, and what an unknown name does. For **which glyphs exist**, the searchable catalogue is `Foundations / Icons`.

```tsx
<Icon name="player-play" />
<Icon name="volume" size={20} color="textDim" />
<Icon name="settings" thickness={1.8} />
```

<Do>

<Dont>

- Hard-code a hex where a token exists; the glyph then misses a palette change.
</Dont>
