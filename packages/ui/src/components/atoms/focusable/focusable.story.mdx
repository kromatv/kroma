## Delegating the element it renders

`asChild` hands the control's host element to its one child, so a route becomes a real `<a href>` the browser can open in a tab, copy or middle-click. The child's own children are the control's content, and everything the control resolved (its coats, its ref, its a11y state) is merged onto the child under [`lib/slot`](../../../lib/slot.tsx)'s rules: the child keeps what the router put on it.

```tsx
<Focusable sv={genreTile} label={label} asChild>
  <RouteLink to="/genres/$id" params={{ id }}>
    <Text>{label}</Text>
  </RouteLink>
</Focusable>
```

Where the content has to follow the interaction state, the render function returns the element instead:

```tsx
<Focusable sv={sideNavRow} vars={{ current }} asChild>
  {({ slots }) => (
    <RouteLink to={to}>
      <Icon name={icon} color={slots.glyph.color} />
    </RouteLink>
  )}
</Focusable>
```

Activation belongs to the element on this path: `<Focusable>` wires no press, which is what keeps a plain click to one navigation and leaves a modified or middle click to the browser. Where there is no document, and under the spatial navigator, the element is dropped and the pressable renders its content instead, so a control that has to work on either passes `onPress` too.
