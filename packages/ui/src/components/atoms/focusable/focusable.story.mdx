The kit's only focusable primitive. Every control reachable with the remote is one, and it carries the 10-foot affordance: a solid ring in the theme's accent plus a dark elevation, with an optional scale.

## Where the ring goes

One ring, everywhere: the theme's accent, four pixels wide. A control never picks where it is drawn. On its own it stands six pixels off the control and follows its corner; inside a container whose members abut or are clipped, the container says `inside` once and every control in it lays the same ring on its own inner edge, so the ring and the focus fill under it are one shape.

## Delegating the element it renders

`asChild` hands the control's host element to its one child, so a route becomes a real `<a href>` the browser can open in a tab, copy or middle-click. The child's own children are the control's content, and everything the control resolved (its coats, its ref, its a11y state) is merged onto the child under [`lib/slot`](../../../lib/slot.component.tsx)'s rules: the child keeps what the router put on it.

```tsx
<Focusable sv={genreTile} label={label} asChild>
  <RouteLink to="/genres/$id" params={{ id }}>
    <Text>{label}</Text>
  </RouteLink>
</Focusable>
```

Where the content has to follow the interaction state, the render function returns the element instead:

```tsx
<Focusable sv={sideNavRow} vars={{ current }} asChild>
  {({ slots }) => (
    <RouteLink to={to}>
      <Icon name={icon} color={slots.glyph.color} />
    </RouteLink>
  )}
</Focusable>
```

Activation belongs to the element on this path: `<Focusable>` wires no press, which is what keeps a plain click to one navigation and leaves a modified or middle click to the browser. Where there is no document, and under the spatial navigator, the element is dropped and the pressable renders its content instead, so a control that has to work on either passes `onPress` too.
