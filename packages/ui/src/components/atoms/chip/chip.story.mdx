A filter or a choice in a row. The active state is carried by the **fill**, never by text color alone: amber on the three washed variants, and ink on `outline`, whose screens have already spent their amber on a Play button. A filter that counts something says so in the chip: `dot` for what it is counting, `count` for how many, both in the chip's own ink so they stay legible whichever state it is in.

```tsx
<Chip label="Sci-Fi" active={selected} onPress={toggle} />

// A filter row that counts: the dot is the status colour, the count trails it.
<Chip label="Running" dot={colors.accent} count={7}
      active={bucket === 'active'} onPress={() => setBucket('active')} />
```

<Do>
- Use `subtle` over ambient artwork. It recedes until focused.
- Use `outline` where the accent is already carrying a primary action on the same screen.
- Use the `tv` size on any 10-foot screen: the small target is a mouse target.
- Give `dot` the colour the status is drawn in everywhere else, and let the chip decide how to keep it visible.
</Do>

<Dont>
- Use a Chip for a one-off action; that's a Button in a smaller coat.
- Paint a dot yourself next to the label: on the active fill your colour is the fill's colour, and it disappears.
</Dont>
