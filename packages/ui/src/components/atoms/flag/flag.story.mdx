A country's flag, for the one place a flag says something words do not: which language a row is in, before the reader can read it. Drawn square from vectors (`country-flag-icons`, MIT), so every flag takes the same box whatever its own proportions, and never as an emoji, which some televisions draw as two letters and Windows does not draw at all. A hairline edge keeps a white field readable on a white ground, and the flag says nothing to assistive tech, since the words beside it name the thing.

The kit draws only the flags a language uses. `isFlagRegion` says whether it draws one, so a caller holding a region it does not draw shows something neutral instead.

```tsx
const region = flagRegion(locale);
{isFlagRegion(region) ? <Flag region={region} size={16} /> : <Icon name="language" />}
```
