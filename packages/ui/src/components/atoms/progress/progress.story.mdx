import { defineStory } from '@kroma/workbench/story';
import { Box } from '#ui/components/atoms/box';
import { Progress } from './progress';

export const story = defineStory({
  group: 'Feedback',
  // It takes whatever width it is given, so a range rather than the one width
  // that would hide a bug at any other.
  width: { min: 240, max: 640 },
  component: Progress,
  args: {
    value: 0.42,
    buffered: 0.68,
    thickness: 4,
    rounded: true,
    indeterminate: false,
    waiting: false,
  },
  controls: {
    value: { min: 0, max: 1, step: 0.05 },
    buffered: { min: 0, max: 1, step: 0.05 },
    thickness: { min: 2, max: 16, step: 1 },
  },
});

The playback progress bar: the one running under a partially watched thumbnail, and the player's own. The value is clamped to 0..1 by the component itself, and the fill eases to each new one. `indeterminate` sweeps a segment across the track for work whose share is unknown.

<Scene name="Determinate and indeterminate">
  The same bar answering a known share, and answering "still working".

  {story.take(({ value, thickness, rounded }) => (
    <Box gap={24} self="stretch">
      <Progress value={value} thickness={thickness} rounded={rounded} />
      <Progress thickness={thickness} rounded={rounded} indeterminate />
    </Box>
  ))}
</Scene>

<Scene name="Loaded ahead, and stalled">
  A stream's bar reports three things at once: how far the viewer got, how much has landed, and whether the next frame is there yet. `buffered` draws the loaded range as a dimmer fill under the played one, and a range that trails `value` is held at `value`, since nothing plays before it loads.

  `waiting` breathes the track ahead of the fill instead of replacing the position with a sweep, so an operator watching a stall still reads where the viewer stopped. It works with no `buffered` at all, which is what a client that reports no loaded range gets.

  {story.take(({ value, buffered, thickness, rounded }) => (
    <Box gap={24} self="stretch">
      <Progress value={value} buffered={buffered} thickness={thickness} rounded={rounded} />
      <Progress value={value} buffered={buffered} thickness={thickness} rounded={rounded} waiting />
      <Progress value={value} thickness={thickness} rounded={rounded} waiting />
    </Box>
  ))}
</Scene>
