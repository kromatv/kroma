  group: 'Layout',
  // A band takes the column it is put in, so it is given a range: the title, its
  // action and the rule have to hold together at both ends of it.
  width: { min: 320, max: 720 },
  args: { title: 'Playback', gap: 16 },
  controls: { gap: { min: 0, max: 40, step: 4 } },
  render: ({ title, gap }) => (
    <Section.Root gap={gap}>
      <Section.Header>
        <Section.Title>{title}</Section.Title>
        <Section.Actions>
          <Chip variant="subtle" label="See all" />
        </Section.Actions>
      </Section.Header>
      <Text color="textMuted">First line of the band</Text>
      <Text color="textMuted">Second line of the band</Text>
    </Section.Root>
  ),
});

A titled band: an overline, a rule, and the content. Every settings screen had its own copy of this arrangement, with slightly different spacing each time.

Composed: `Root` owns the column, and `Header`, `Title` and `Actions` are named parts. The rule belongs to the `Header`, which is what separates the header from the content, so a band written without one has no rule to explain. `Root` sorts its direct children once: a `Header` sits at the top, everything else is content spaced by `gap`.

```tsx
<Section.Root>
  <Section.Header>
    <Section.Title>Playback</Section.Title>
  </Section.Header>
  <PlaybackCard />
</Section.Root>

// The header takes the band's controls too.
<Section.Root>
  <Section.Header>
    <Section.Title>Playback</Section.Title>
    <Section.Actions>
      <Chip variant="subtle" label="See all" onPress={seeAll} />
    </Section.Actions>
  </Section.Header>
  <PlaybackCard />
</Section.Root>
```
