The way back, drawn once: a scrimmed chevron disc that floats over artwork, fills amber on focus for the 10-foot targets, and grows a touch halo on the phone. Pass `label={t('common.back')}`, since the default is plain English.

```tsx
<BackButton onPress={router.back} label={t('common.back')} />
<BackButton variant="ghost" diameter={40} onPress={router.back} label={t('common.back')} />
```

<Do>

- Use `ghost` in a page header that already sits on the page colour.
</Do>
