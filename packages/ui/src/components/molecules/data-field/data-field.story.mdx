import { defineStory } from '@kroma/workbench/story';
import { Box } from '#ui/components/atoms/box';
import { Text } from '#ui/components/atoms/text';
import { DataField } from './data-field';

export const story = defineStory({
  group: 'Layout',
  component: DataField.Root,
  args: { size: 'md' },
  controls: { size: ['sm', 'md', 'tv'] },
  render: ({ size }) => (
    <DataField.Root size={size}>
      <DataField.Label>Runtime</DataField.Label>
      <DataField.Value>2h 04m</DataField.Value>
    </DataField.Root>
  ),
});

One fact, read: an overline naming it and the value under it. Not a `Field`. Nothing here is editable, so there is no shell, no focus ring and no error state. The label is always the ramp's overline role, which is what stops six screens drifting to six label sizes.

```tsx
<DataField.Root>
  <DataField.Label>Runtime</DataField.Label>
  <DataField.Value>2h 04m</DataField.Value>
</DataField.Root>

<DataField.Root>
  <DataField.Label>Network</DataField.Label>
  <DataField.Value lines={1}>{session.network}</DataField.Value>
</DataField.Root>
```

<Do>
- Reach for `lines={1}` in a grid of readouts, so a long value truncates instead of widening its column.
- Let `size` come from the app (`setEntryDefaults`) and state it only where one readout is louder than its neighbours.
</Do>

<Dont>
- Use it to label a control. That is `Field`, which owns the shell and the error.
- Put a sentence in the value; a readout is a fact, not a paragraph.
</Dont>
