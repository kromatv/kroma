The remote-driven server-URL grid: ten keys a row, the layout's letters plus the URL specials, and a clear / dot / submit tail row. Every key is a `<Focusable>`, so the spatial focus nav reaches it and OK activates it. **The letter order is the caller's**: a keyboard that read a settings store would tie the kit to one app's preferences, so the host passes `letters` (the TV reads its persisted device preference once per mount). Its sibling is `<SearchKeyboard>`: two components, not one with a `layout` switch.

```tsx
<UrlKeyboard
  value={host}
  onValueChange={setHost}
  onSubmit={connect}
  submitLabel={t('connect.connect')}
  letters={getKeyboardLayoutPref()}
/>
```

</Do>

<Dont>
