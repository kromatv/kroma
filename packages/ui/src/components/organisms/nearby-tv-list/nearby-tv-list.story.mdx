The televisions waiting on this network, as rows, drawn once for the two shells that ask: the browser's connect screen and the phone's. A row is the set's name, its platform under that, and the check string it is printing on its own screen - which is there so a television that named itself after yours can be told from yours, not because anyone is usually asked to type it. What a tap DOES lives in `useHandoffPicker`; this says only what a row looks like while it is doing it, and it says it ON the row: a spinner while the grant is in flight, then a tick or the reason it failed, never a notice somewhere else on the page. A finished row stops being pressable, because the beacon behind it is spent and the row is only still there to be read. `t` is a prop rather than the kit's own `useT` because the phone mounts its own translator and would read an empty catalogue here otherwise; the language lens in the toolbar moves these rows.

```tsx
const { rows, asking, outcomeFor, start, grant, stopAsking } = useHandoffPicker({ devices, connect });

<NearbyTvList
  devices={rows}
  connectingHandle={connecting?.handle}
  outcomeFor={outcomeFor}
  onSelect={start}
  t={t}
/>
```
