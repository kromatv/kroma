The interface language, for a list of ten languages or forty. A segmented control stops working at four, and a select of names stops working once a reader cannot read the names on screen, so every row says a language three ways: its **flag**, its **own name** written in it (with `lang`, so a screen reader speaks it and Han characters take the right glyphs), and its **name in the language on screen** beside it. A language still being translated wears a **Beta** tag, and the one picked a tick. The whole row is the control.

**Ordered to be found.** A long list leads with **Suggested**: the language picked, then each one the device asks for, matched the way a browser's language is (`pt-BR` finds `pt`, `zh-CN` finds `zh-Hans`). Then **all languages**, sorted by the name the reader knows them by, as their language sorts. The suggestions are frozen when the list is drawn, so a pick does not make its row jump.

**Searched where there is a keyboard.** Over eight languages, a field above the list matches either name or the code, whatever the case and the accents (`espanol`, `ESP` and `es` all find Español). A television has no keyboard, so there the list sits in a dialog the remote walks, opened on the picked row. Only the list scrolls; the title and the search stay put.

**Flags are drawn, never emoji**, from `country-flag-icons`, and the flag of a locale is the country CLDR finds it most likely written in (`flagRegion` in `@kromatv/i18n`, which kroma.tv reads too): English wears the United States', as the catalog spells American, and Portuguese Brazil's. A locale with a region subtag wears that region's flag; one no one country speaks for, such as Arabic, wears the neutral language glyph in the same box rather than a wrong flag.
