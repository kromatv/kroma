What a film says when it opens where it was left. It states the time as a fact, because by the time anyone reads it the picture has already resumed, and it offers the one thing that fact makes anyone want: the beginning. The rule along its foot drains while the window runs, so the prompt going away is never a surprise.

It shares the skip pill's corner and takes the same `lift`, and the player draws only one of the two at a time. `focused` comes from the nav machine rather than from the DOM, so on a television the remote reaches it without the picture ever losing the real focus.

```tsx
<ResumePrompt
  at={resumedAt}
  shown={notice.shown}
  secondsLeft={notice.secondsLeft}
  lift={transportHeight + gap}
  onStartOver={() => controller.seekTo(0)}
/>
```

Inside `<Player.Root>` none of that is a caller's business: write `<Player.Resume at={resumedAt} />` and the chrome owns the clock, the corner and the D-pad stop.
