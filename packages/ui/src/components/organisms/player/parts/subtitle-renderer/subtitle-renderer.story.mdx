One position-driven subtitle renderer for the browser AND the television. It fetches the active track's WebVTT itself and caches the parsed cues per url, because a cross-origin `<track>` element silently never loads its cues when the app and the media server are on different origins, which is the normal case for a self-hosted server. Position is interpolated locally between the player's updates, so the caption changes on the frame it should rather than up to 250ms late.
