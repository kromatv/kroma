# Join the KROMA beta

KROMA's apps are not in the app stores yet. Testers install them through
TestFlight, Google Play's test program, or a file. This page says where to
start for each device, and how to tell us what goes wrong.

## Before you start

KROMA plays films from **your own server**. The app contains no films. You
need a KROMA server on your network, or the address of someone else's server
and an invitation from its owner. To install a server, see the
[setup guides](docs/setup/README.md).

## Install the app

| Device | Guide |
| --- | --- |
| iPhone, iPad | [TestFlight](docs/setup/mobile.md#iphone-and-ipad) |
| Apple TV | [TestFlight, joined from an iPhone](docs/setup/apple-tv.md) |
| Android phone or tablet | [Google Play test, or the `.apk`](docs/setup/mobile.md#android-phone-and-tablet) |
| Android TV, Google TV, NVIDIA Shield | [Google Play test](docs/setup/android-tv.md#install-from-google-play) |
| Fire TV, projector without Google Play | [the `.apk` file](docs/setup/android-tv.md#install-without-google-play) |
| Samsung TV | [developer mode and a computer](docs/setup/samsung-tv.md) |
| LG TV | [Developer Mode and a computer](docs/setup/lg-tv.md) |
| Computer | [an installer](docs/setup/desktop.md), or your server's address in a browser |

The links you need to join:

- TestFlight, for iPhone, iPad and Apple TV:
  [testflight.apple.com/join/ZjgQdunW](https://testflight.apple.com/join/ZjgQdunW)
- Google Play, for Android phones and TVs: first the
  [tester group](https://groups.google.com/g/kroma-android-beta), then the
  [test page](https://play.google.com/apps/testing/tv.kroma.app)

## Send feedback

Tell us what you were doing, on which device, with which KROMA version.
Screenshots help.

- iPhone and iPad: **Send Beta Feedback** in TestFlight, or take a screenshot
  in KROMA and share it from there.
- Android: the private feedback form on KROMA's Google Play page.
- Email: beta@kroma.tv
- Or [open an issue](https://github.com/kromatv/kroma/issues).

If something does not work, check [Troubleshooting](docs/setup/troubleshooting.md)
first.
