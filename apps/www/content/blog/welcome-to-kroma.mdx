Running your own media library today often looks like this: Jellyfin to watch,
Sonarr and Radarr for shows and films, Prowlarr for indexers, qBittorrent to
download, Gluetun for the VPN. Six containers, six configuration files, and six
things that break, each in its own way, never at the same time.

KROMA starts from a simple idea. All of that should fit in one app.

## One server

KROMA is one program, written in Rust. It installs with one command, starts in
milliseconds and uses almost no CPU when nobody is watching.

```bash
docker run -d -p 4040:4040 \
  -e KROMA_MEDIA_DIRS=/media \
  -v /volume1/video:/media \
  -v kroma-data:/data \
  ghcr.io/kromatv/kroma:latest
```

Point it at your film and show folders and it does the rest. It tells a film
from an episode by its file name, groups episodes into seasons, and fetches
posters and summaries by itself, with no API key to create.

## The rest, as modules

A fresh install is a media server and nothing more. You add the rest when you
need it, in one click from the admin. Each tool from the usual stack has its
counterpart:

- Prowlarr becomes the Indexers module.
- qBittorrent becomes the Torrent downloads module, or stays where it is if you
  already run it.
- Sonarr and Radarr become the Acquisition module. You ask for a title, and it
  picks the best release, downloads it and files it.
- Gluetun becomes the VPN module, a WireGuard tunnel that cuts all traffic if the
  tunnel drops.

Some modules have no counterpart in the usual stack. Whisper writes subtitles on
your own machine, and Embeddings adds rows picked for you to the home screen.

A module runs inside the server, isolated, and reaches only what it declared,
such as the network, some files or its own database. Each one ships on its own
schedule, without waiting for a new server release.

## Playing the file as it is

Re-encoding a video on the fly keeps your NAS busy for the whole film. KROMA
avoids it whenever it can. When the device can read the file, HDR and 10-bit
included, the server sends it the original file, untouched. The TV or the phone
decodes it with its own video chip.

Re-encoding only happens when the device really cannot read the file, and it
uses hardware acceleration when the machine has it.

## The same KROMA on every screen

Web, iPhone, iPad, Android, Samsung and LG TVs, Apple TV, Android TV, Mac,
Windows, Linux, Steam Deck. Every one of these apps comes from the same code,
with the same design: one charcoal grey, one amber, two typefaces, and no emoji.

Several people can share one server, each with their own profile, a PIN if they
want one, and the spot where they stopped. A TV on the same network shows up in
the phone app and signs in with one tap.

## Yours, for real

KROMA is open source, under the AGPL. Your library and what you watch stay on
your network. No account with us, no subscription, and no central service that
could shut down one day and take your library with it.
