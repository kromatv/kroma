# Store listing copy: LG Content Store and Samsung Apps TV

Ready-to-paste text for both TV submissions. Shared, because the two listings
should say the same thing: divergent descriptions of the same app are a content-
test question nobody wants to answer twice.

**The one rule this copy follows:** it describes the *client*, and only the
client. KROMA the product also indexes, downloads and manages media, but none of
that is in this app, or in the server as it ships (see the LG
[STORE.md §10](../clients/webos/STORE.md) / Samsung
[STORE.md §10](../clients/tizen/STORE.md)). The app is a player for a server the
viewer runs. Every sentence here is true of the thing being submitted, which is
what makes it defensible when a reviewer reads it next to the binary.

So: no "torrent", no "indexer", no "download", no "VPN", and no naming of any
title, studio or service anywhere in the listing or the screenshots.

## Long description (English, mandatory default language)

```
KROMA turns your television into the front end for a media server you run yourself.

Point it at your KROMA server (on your home network, or anywhere you can reach it) and your own library is on the big screen: films, series, where you left off, and per-profile suggestions, in a calm amber-on-charcoal interface designed for a remote control rather than a mouse.

DIRECT PLAY, NOT TRANSCODING
KROMA hands your files to the television untouched and lets the panel's own decoder do the work. HEVC/H.265, 10-bit and HDR included, plays at full quality: no server sweating over a re-encode, no quality lost on the way to the screen.

BUILT FOR THE REMOTE
Every screen is driven by the D-pad. Arrows move, OK opens, Back returns; the media keys drive the player. Focus is always visible and always somewhere, so the remote never stops working.

PROFILES THAT STAY SEPARATE
Each profile keeps its own progress, its own list and its own language and subtitle preferences. A profile can be PIN-locked. Pair one on this television in seconds with Quick Connect, from a device already signed in.

MORE THAN ONE SERVER
Add as many servers as you like and switch between them; the app shows which are reachable before you pick one.

CAST FROM YOUR PHONE
Send a title from the KROMA mobile app to this television and drive playback from your hand.

WHAT KROMA IS NOT
It is not a streaming service. There is no catalogue to subscribe to, nothing to buy, and no account to create with us. The app shows only what your own server serves. It collects nothing about you: no analytics, no tracking, no advertising.

Requires a KROMA server, which is free and open source (MIT). See kroma.tv.
```

## Keywords

Neither store wants a title or a studio name here: those are the words that
attract a content-test question, and they describe someone else's product anyway.

Samsung takes at least 3 **comma-separated** tags per language:

```
media server, self-hosted, home media, personal library, video player, direct play, HEVC, HDR, subtitles, home network
```

LG separates them with **spaces**, so the same list becomes:

```
media server self-hosted home media personal library video player direct play HEVC HDR subtitles home network
```
